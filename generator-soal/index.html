Rancang soal

Agar otomatis, isi API key Gemini (gratis) sekali di ⚙ Pengaturan. Tanpa API key, gunakan mode salin prompt.

⚠️ Soal buatan AI adalah draf. Periksa kebenaran isi, terutama ayat, hadis, lafal doa, dan tulisan Arab. Soal bertanda kuning wajib dicek. Klik teks mana pun untuk mengeditnya.

Bank Soal

Bank soal tersimpan di peramban (browser) perangkat ini. Ekspor secara berkala sebagai cadangan, atau untuk dipindahkan ke perangkat lain seperti papan interaktif kelas.

Pengaturan

Isi sekali saja. Dipakai bersama oleh Generator Soal dan Kisi-kisi.

Gratis: buka aistudio.google.com/apikey, masuk dengan akun Google, klik Create API key, lalu salin ke sini. Kuota gratis terbatas per menit dan per hari.

Dapatkan di console.anthropic.com → API Keys (perlu isi saldo).

API key disimpan hanya di peramban perangkat ini. Jangan isi di komputer umum atau milik bersama.

Buat soal tanpa API key

  1. Klik Salin prompt.
  2. Buka claude.ai, Gemini, atau ChatGPT, lalu tempel dan kirim.
  3. Salin seluruh jawaban AI (berupa JSON), tempel di kotak bawah, lalu klik Proses hasil.
Sedang menyusun soal…Biasanya 20–90 detik, tergantung jumlah soal.
